- [ ] Tugas utama hari ini selesai / dipindah dengan alasan
- [ ] Log Harian SPV terisi & rencana besok ditulis

### E2. Mingguan

- [ ] Rencana Mingguan Tim dibagikan (Senin)
- [ ] Kunjungan/audit cabang minggu ini terlaksana sesuai jadwal
- [ ] Laporan audit diperiksa ≤ 2 hari kerja setelah audit
- [ ] Rekap keluhan & survei mingguan terbit (Jumat)
- [ ] Keluhan per 1.000 pasien per cabang dicek vs ambang; cabang di atas ambang dijadwalkan tinjauan
- [ ] Progres pemulihan Landak dicatat
- [ ] Log backup mingguan dicek; backup gagal diulang
- [ ] Log tiket IT mingguan dicek (respons ≤ 30 menit, P1 selesai ≤ 2 jam)
- [ ] Keluhan eskalasi minggu lalu diverifikasi penyelesaiannya
- [ ] Rencana minggu depan disusun (Sabtu)

### E3. Akhir Bulan

- [ ] Dashboard bulan lalu terbit ≤ tgl 5; akurasi data ≥ 98%
- [ ] Audit 4 cabang 100% terlaksana; laporan final
- [ ] Mystery patient 4 cabang terlaksana; jadwal tidak bocor
- [ ] Skor layanan per cabang (audit + mystery patient) direkap
- [ ] Temuan audit lewat tenggat sudah dieskalasi
- [ ] Laporan pola keluhan bulanan & temuan berulang terbit
- [ ] Usulan perbaikan SOP dikirim ke Dept. HC (bila ada)
- [ ] Laporan suara pasien per cabang dibahas dengan Kepala Cabang
- [ ] Coaching 1-on-1 Auditor, Data Analyst, IT Support selesai
- [ ] Penilaian kinerja tim diserahkan ke Manager Mutu & CX
- [ ] Training/coaching CRM tercatat (bila ada CRM baru / pengajuan KC)
- [ ] Kuartalan (Mar, Jun, Sep, Des): reviu akses & uji pemulihan backup
- [ ] Rapat akhir bulan dengan Manager; jadwal bulan depan disusun
